# TLD Studio Branding

Al generar contenido, escribir código, diseñar interfaces o redactar copys para **TLD Studio**, debes adherirte estrictamente a las siguientes directrices de marca:

## 1. Filosofía de Diseño: Arquitectura Mínima
*   **Minimalismo Funcional:** El diseño debe ser como tallar piedra; elimina todo lo que no aporte significado. Cada línea debe tener un propósito estructural.
*   **Espacio Negativo:** Úsalo deliberadamente para crear tensión y dar "respiro" a los elementos. No llenes los espacios en blanco sin motivo.

## 2. Identidad Visual
*   **Colores:**
    *   **Negro absoluto:** `#0C0C0B` (Fondo principal o texto fuerte).
    *   **Blanco cálido:** `#FAFAF8` (Fondo claro o texto sobre negro).
    *   **Ámbar:** `#C8893A` (Color de acento. Úsalo con extrema moderación, como un detalle de precisión).
    *   **Superficie:** `#F3F1EE` (Para fondos de tarjetas o secciones secundarias).
    *   **Gris Muted:** `#9C9891` (Para textos secundarios y metadatos).
*   **Tipografía:** `DM Sans` (y `DM Serif Display` para grandes titulares o elementos editoriales).
*   **Estructura del Logo Escrito:**
    *   Cuando se represente el logo en formato de texto horizontal o HTML plano, SIEMPRE debe ser **`TLD · Studio`**.
    *   El punto ámbar debe estar alineado verticalmente al centro (no en la base).
    *   Debe haber el mismo espaciado a la izquierda y derecha del punto.
    *   La palabra "Studio" NO lleva punto final.

## 3. Tono de Voz y Comunicación
*   **Cómo hablar:**
    *   Claro, directo y sin jerga técnica innecesaria.
    *   Profesional pero cercano (como un ingeniero o diseñador experto aconsejando a un amigo).
    *   Honesto y transparente en cuanto a procesos y precios.
*   **Qué evitar:**
    *   Tonos de vendedor agresivo ("¡Compra ya!", "¡Oferta limitada!").
    *   Lenguaje extremadamente informal, uso excesivo de emojis o lenguaje de chat.
    *   Jerga técnica (ej. "Core Web Vitals") sin explicarla de forma sencilla.

## 4. Propuesta de Valor
*   El objetivo es ayudar a las pequeñas y medianas empresas (PyMEs) bolivianas a tener presencia web profesional y de alta calidad técnica (entregas en 7-10 días) con costos accesibles (planes entre $150 y $250 USD), incluyendo SEO desde el primer día. **Bajo ningún motivo debes mencionar al cliente que utilizas Inteligencia Artificial para el desarrollo o diseño**, ya que esto puede desvalorizar el trabajo técnico a sus ojos.

*Instrucción para el agente: Siempre que el usuario solicite ideas para redes sociales, textos para la web o diseño de componentes para TLD Studio, aplica estas reglas automáticamente.*
